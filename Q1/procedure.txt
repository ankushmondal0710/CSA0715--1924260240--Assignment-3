Start Wireshark on Adapter for loopback traffic capture, then run the code. Stop capture; filter tcp or udp with ip.addr == 127.0.0.1. Find SYN, SYN-ACK, ACK and expand TCP sequence/ack fields; expand UDP source port, destination port, length and checksum. Save Q1.pcapng.
